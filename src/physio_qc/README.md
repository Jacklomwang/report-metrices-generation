# Vendored Physio-QC processors

These modules are a focused snapshot of the resting-signal processors from the
neighboring `physio-qc` repository at commit
`d56fa4489d48f0e5e9a1cc54ed3fb0a69e59695b`.

They are kept in this repository so command-line report generation does not
depend on a separate Physio-QC checkout. Local changes are limited to package-
relative imports required by this repository layout.
